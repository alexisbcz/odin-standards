### Added

- `STANDARDS.md` with layout, naming, allocator, error, documentation, versioning and commit rules.
- A working library skeleton in `templates/` with tests and an example.
- The `OdinDocs` Vale style, an Odin vocabulary and a `.vale.ini`.
- A GitHub Actions workflow for Linux and macOS that pins Odin `dev-2026-09`.
- `ROADMAP.md` with a prioritized plan for the Odin ecosystem.
